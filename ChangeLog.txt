Actipass Version 2026.11.7 (2026-11-27)
#############################################

Changes:
1. The raw+posture intensity algorithm (EXPERIMENTAL: check its results before you use them) is now part of this
   repository in a MATLAB version: algorithms/intensityPAEE.m with the models in algorithms/IntensityModels.json
   (setting INT_ALG "raw+posture (M)"; no R needed, about 1-2 s for a 7-day recording). The original R version
   ("raw+posture (R)", needs R) is kept in the programs but is not included here; it will be hosted in a separate
   repository. Both versions use the same features and models and give the same PAEE (checked on nine
   recordings: differences <5e-15 kJ/kg/min, no changed intensity class). Settings saved with "raw+posture" are
   read as "raw+posture (R)" (library/LoadSettings.m, new library/intensityAlg.m).
2. Both versions write "<ID> - PAEE.bin" (PAEE per 10 s window with the time, activity and the features the
   models use), an Actipass binary table (new library/readAPBin.m and writeAPBin.m). "<ID> - rawAcc.mat",
   "- ActOnly1s.mat", "- PAEE.csv" and "- intensity_calculation.rds" are no longer written. stats/genStats.m reads
   PAEE.bin, or the PAEE.csv of projects processed earlier. The R version is about 2x faster, and its temporary
   input files (~0.5 GB for 7 days) go to the local temp folder instead of the project folder.
3. Statistics (stats/genStats.m): the 10 s PAEE is applied to the seconds of its own window. Before, each second
   took the PAEE of the nearest window start, so the seconds 6-9 of a window took the next window's PAEE (and
   second 5 either). Intensity times change slightly (e.g. a few minutes per day between classes).
4. algorithms/genTrnkVariables.m: the sample rate of the trunk angles is the resample frequency of processing
   (ParamsAP.Fs) instead of a fixed 25 Hz (results unchanged at the default 25 Hz).
5. mergeSleepData.m moved from algorithms/ to stats/ (it merges the sleep data of a processed project).
6. Actipass desktop app 2026.11.7-alpha (desktop/): the two raw+posture versions in the settings; the source of
   the 2026.11.6-alpha changes is now also here (engine restart after sleep, licence files of readGT3xMex in the
   installer, `npm run clean`) (see desktop/CHANGELOG.md).

   Actipass_UI.conf (the same file on Windows). Licence file names (ActiPASS.lic/.key) are unchanged.
2. The "raw+posture" intensity algorithm is marked as experimental: check its results before you use them.
3. Example configuration files (conf/): Actipass_UI.conf has the settings INT_ALG, varsBout and the personal data
   settings PERSDATA, PERSRMR and pers_file; the unused VarsBout was removed from AktDetect_UI.conf.

   a shortcut from the Statistics page to the statistics options, help for the automatic time-in-bed settings and
   the quality check thresholds. The generic protocol layer of the engine is now published in
   desktop/engine-matlab/ (see desktop/CHANGELOG.md and desktop/engine-matlab/README.md).
5. Fixed (stats/genStats.m): generating statistics crashed ("Unrecognized function or variable 'finlTrnkDT'")
   when the trunk accelerometer was off but "Save trunk angle data" (SAVETRNKD) was on.
6. Kneeling (calf accelerometer) gets an intensity: the new algorithm parameter MET_Kneel (default 1.55 MET, as
   standing; in the 2024 Adult Compendium static kneeling equals standing quietly) or, with a cadence, the walking
   MET of that cadence, as for "Other". Before, kneeling time was in none of the intensity classes. With the
   raw+posture algorithm kneeling gets the same values as PAEE. conf/AktDetect_UI.conf has MET_Kneel.
7. Statistics of projects with batches processed with and without the trunk or calf accelerometer: participants
   without calf data get empty (NaN) kneeling variables (Kneel, TooMuchKneel, AngleCalfWalk) instead of 0, and
   participants processed without the trunk get empty trunk variables (trunk data files of an earlier batch are
   no longer used); a warning lists them. A warning also names batches processed with the trunk or calf
   accelerometer when it is off in the statistics.
8. stats/genTrnkVariables.m: trunk variables use the resample frequency of processing (algorithm parameter Fs)
   instead of a fixed 25 Hz.


Actipass Version 2026.11.3 (2026-11-22)
#############################################
(summary of the private versions 2026.10.1 to 2026.11.3 since the last public release)

New: Actipass desktop app
1. A new desktop app with a new user interface is released together with the classic app, with the same
   version number and the same processing. Its source code is published in ./desktop under GPL-3.0-or-later
   (see desktop/README.md and desktop/CHANGELOG.md); the processing engine it starts is distributed in
   compiled form under the End-User License Agreement.

Changes and new features:
1. Stats generation can save a time series output at a given epoch length, and stops early with a clear message
   when the batch settings conflict with the stats settings.
2. Integrated whole-body vibration (WBV, ISO 2631) prediction for sitting segments.
3. Bout variables can be selected in the UI.
4. "raw+posture" intensity algorithm: the R module is about 7 times faster and needs only the R libraries
   data.table, earth and R.matlab; a readable run log (<ID> - IntAlgOut.txt); the library check reports an
   error when a library cannot be installed.
5. Orientation quality check: the 90 degree rotation test is done per worn period and reported separately;
   not-worn segments get the default orientation; a possible orientation change within a worn period is warned
   about.
6. Diary: diary times are matched to the processed data on whole seconds; diary times that are not on a whole
   second, or fall on no processed second, are warned about (Diary_Warnings).
7. Merge sleep data, sit-to-stand angular velocity and clinical sit-to-stand counts: optional file exclusion
   based on the automatic QC (None, NotOK, Check+NotOK).
8. The Image Processing Toolbox is no longer needed.
9. Licence check and request read the network adapters with PowerShell Get-NetAdapter (getmac misses some
   modern adapters, e.g. Wi-Fi 7).
10. Stats generation with personal data (optional): a table with SubjectID, Age, Sex, Height and Weight. Each
    person's height replaces 170 cm in the height-adjusted cadence-MET equation (O'Brien et al. 2020), and for
    raw+posture the person's resting metabolic rate (Mifflin-St Jeor) can be 1 MET of the PAEE intensity cut-offs.
11. Newly published source files: mergeSleepData, genClinicSitToStandTable, calculate_wbv_segments,
    load_AX3_iso2631, iso2631_wbv, FindNonWearTrunk (algorithms); CalibrateData, downsampleTable,
    matchDiaryTicks, timeToSec, MaxIncTid, movingMode, removeShortRuns, resampleAcc, toActiPASSFrame,
    readCalFile, VisualizeActvts, findDistributions, readPersonalData (library); cli_diary_tick_warnings (cli).

Bugfixes:
1. Resampling: in about half of the recordings the resampled data had one sample too few, so the samples drifted
   late by up to one sample by the end of the data. The activity of about 0.2-0.5% of the seconds can differ.
2. SENS bin/hex files: the time-zone offset is now the offset at the start of the recording, not at the time of
   processing (recordings made in summer time and processed in winter time, or the reverse, were shifted one hour).
3. "raw+posture" intensity algorithm: files whose raw data ended a few samples past a whole second got no PAEE;
   the peak_frequencies_* features were always 1 (not used by the PAEE models).
4. Diary: an invalid diary no longer gives an error when the reference position is taken from the diary; a first
   diary event before the data start is moved to the nearest whole second of the data start.
5. Tools: sit-to-stand angular velocity works with a single subject; clinical sit-to-stand counts keep per-file
   errors and give correct test start/end times; WBV prediction works for older projects and has fewer edge-case
   errors.
6. Device IDs (Movisens serial number, IDs as text), trunk/calf WAV conversion and reference positions, and several
   robustness fixes in batch processing.
7. Actipass CLI 2026.11.3: the same resampling, diary and SENS fixes, plus the missing dependency brewermap.m;
   ReadMe_CLI.txt and Usage_CLI.txt now match the program (output file names, modes, return codes).
